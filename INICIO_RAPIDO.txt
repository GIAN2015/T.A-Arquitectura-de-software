╔═══════════════════════════════════════════════════════════════════╗
║                    3. CONFIGURAR IA (OPCIONAL)                    ║
╚═══════════════════════════════════════════════════════════════════╝

Para que la IA funcione al subir informes:

1. Obtén API Key gratis en: https://console.groq.com/
2. Edita el archivo: proyecto_untels/.env
3. Añade la línea:

   GROQ_API_KEY=gsk_tu_clave_aqui

4. Reinicia el servidor

NOTA: Sin API Key, el sistema seguirá funcionando pero NO validará
      automáticamente con IA. Los docentes deberán crear observaciones
      manualmente.

╔═══════════════════════════════════════════════════════════════════╗
║                    4. FLUJO DE USO TÍPICO                         ║
╚═══════════════════════════════════════════════════════════════════╝

ALUMNO:
  1. Login en portal estudiantes
  2. Click "Subir Informe"
  3. Seleccionar archivo .docx
  4. ✨ IA valida automáticamente
  5. Ver observaciones generadas
  6. Esperar revisión del docente

DOCENTE:
  1. Login en portal docentes
  2. Ver lista de informes pendientes
  3. Click en "Revisar" en un informe
  4. Confirmar/Descartar observaciones de la IA
  5. Añadir comentarios
  6. Aprobar o Rechazar

SI RECHAZADO:
  - Alumno ve el rechazo
  - Corrige el documento
  - Reenvía nueva versión
  - El ciclo se repite

╔═══════════════════════════════════════════════════════════════════╗
║                    7. SOLUCIÓN DE PROBLEMAS                       ║
╚═══════════════════════════════════════════════════════════════════╝

Error: "Address already in use"
→ Hay otro servidor corriendo en puerto 8000
→ Solución: python manage.py runserver 8001

Error: "GROQ_API_KEY not found"
→ No está configurada la API Key
→ Solución: Edita .env y añade GROQ_API_KEY=...

Error al subir archivo
→ Verifica que sea .docx
→ Verifica que el archivo no esté corrupto
→ Revisa logs del servidor

Login no funciona
→ Verifica que uses el portal correcto:
  - Estudiantes: /
  - Docentes: /docente/login/
→ Verifica credenciales (distingue mayúsculas/minúsculas)
